# Neersagar ERP
ERP for a packaged mineral-water plant: raw materials & procurement, blow molding, bottling batches, Lab QC quarantine,
zone warehouse ledger, loading/dispatch/gate pass, 20 L returnable jars, maintenance, live updates and Web Push.
Rust + PostgreSQL + a mobile-first static PWA. No GST/invoicing/payments by design.
